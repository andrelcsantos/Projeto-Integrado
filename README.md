#Projeto React

Projeto individual desenvolvido para colocar em prática as disciplinas técnicas
da Sprint 1.

A aplicação permite cadastrar e visualizar informações de uma Biblioteca Digital através de uma API REST.

##Tecnologias
- React
- JavaScript
- JSX
- CSS Modules
- API REST

##Funcionalidades
- Cadastro de informações
- Visualização dos dados cadastrados
- Integração com a API usando GET e POST
- Componentização em React
- Uso de estados
